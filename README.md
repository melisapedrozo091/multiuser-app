# 🚀 Plataforma Multi-Usuario Standalone (Angular + Node/Express + Prisma)

Aplicación web full-stack que desarrollé utilizando **Angular** para el frontend y una API en **Node.js (Express) + Prisma ** conectada a base de datos relacional con Phpadmin y con autenticación centralizada mediante Firebase.

## 🛠️ Stack Tecnológico

* **Frontend:** Angular , TypeScript, RxJS, Chart.js, CSS Custom Properties (Soporte completo para Modo Claro / Modo Oscuro).
* **Backend:** Node.js, Express, TypeScript, Prisma ORM, PostgreSQL / MySQL.
* **Autenticación y Tiempo Real:** Firebase Auth & Firestore / REST API.
* **Control de Versiones:** Git con estrategia de ramas (`main`, `develop`, `feature/*`).

### ⚡ Inicio Rápido (1 solo clic en Windows)
Haz doble clic en el archivo `iniciar-proyecto.bat` en la raíz del proyecto para abrir automáticamente el Backend y el Frontend.

### 1️⃣ Inicio Manual del Backend
```bash
cd backend
npm run dev
```

### 2️⃣ Inicio Manual del Frontend
```bash
cd frontend
npm start
```

* Frontend disponible en: `http://localhost:4200`
* Backend disponible en: `http://localhost:3000`
